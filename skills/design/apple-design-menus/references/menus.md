# Menus

- Label commands concisely and consistently, using familiar action meanings and the platform’s capitalization conventions.
- Add an ellipsis when completing the command requires further information, rather than merely because another view appears.
- Group related commands, prioritize important work, and keep submenus shallow.
- Show current states clearly with appropriate labels or checkmarks.
- Keep icon treatment consistent within groups and use icons purposefully.

Read the relevant menu-type guidance before handling unavailable commands: a menu bar and a context menu do not use identical visibility rules. Review menu content for each selection and mode.

Source: [Apple HIG — Menus](https://developer.apple.com/design/human-interface-guidelines/menus). Checked 2026-09-08.
