# Edit menus

- Prefer the native edit menu and established gestures for selected content.
- Include relevant standard commands and place custom commands near related system actions.
- Allow copying useful noneditable text, and support undo and redo where possible.
- Remove or disable commands according to context and platform behavior.
- Keep custom command names short and distinguish different kinds of deletion when needed.

Test actual text and nontext selections. Reimplementing editing in a decorative custom toolbar can omit familiar commands, data detection, and input behavior people already rely on.

Source: [Apple HIG — Edit menus](https://developer.apple.com/design/human-interface-guidelines/edit-menus). Checked 2026-09-08.
