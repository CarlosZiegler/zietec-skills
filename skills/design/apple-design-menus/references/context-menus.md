# Context menus

- Offer a small set of actions directly relevant to the targeted item.
- Keep these actions available through a discoverable route in the main interface too.
- Hide unavailable contextual items and keep submenus to one level where needed.
- Order and group commands by usefulness; show keyboard shortcuts in main menus instead of context menus.
- Use a preview that makes the target clear on supported platforms.

On iOS and iPadOS, choose an edit menu or a context menu for an item rather than attaching both. Account for destructive consequences without making every ordinary interaction interruptive.

Source: [Apple HIG — Context menus](https://developer.apple.com/design/human-interface-guidelines/context-menus). Checked 2026-09-08.
