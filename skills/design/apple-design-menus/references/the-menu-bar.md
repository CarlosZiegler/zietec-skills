# The menu bar

- Preserve the standard menu set and expected order on Mac and supported iPad versions.
- Keep menu items stable as state changes; show unavailable commands appropriately instead of reshuffling the structure.
- Support established shortcuts and use concise menu titles.
- Add app-specific menus only for meaningful command groups, ordered to reflect the app’s work.
- Provide expected View and Window behavior even in relatively simple apps.

For Mac menu-bar extras, let people choose their presence and avoid depending on an extra as the only route to functionality. Consult current platform sections for exact menu contents and system-managed items.

Source: [Apple HIG — The menu bar](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar). Checked 2026-09-08.
