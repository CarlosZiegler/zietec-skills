# Activity views

- Use the standard Share action to present context-appropriate sharing and other available activities.
- Avoid duplicating common actions already supplied by the system.
- Give custom activities concise titles and recognizable symbols.
- Keep share or action extensions focused and familiar, without stacking additional modal interfaces above them.
- Represent lengthy work in the main app when appropriate.

Review what is actually being shared, including selection, file type, and any permission choices. Sharing a copy and inviting collaboration may need different options even when they begin in the same system surface.

Source: [Apple HIG — Activity views](https://developer.apple.com/design/human-interface-guidelines/activity-views). Checked 2026-09-08.
