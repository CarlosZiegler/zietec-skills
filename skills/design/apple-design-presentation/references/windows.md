# Windows

- Use standard window controls and let content adapt fluidly as windows resize.
- Open additional windows when the task benefits, and consider letting people request a new window for independent content.
- Keep important actions accessible across window states and avoid overlap with system window controls.
- On visionOS, distinguish windows for familiar UI from volumes for rich 3D content, retaining appropriate glass and scaling behavior.

Verify current platform windowing rules and restoration. A window’s initial dimensions are only a starting point; design narrow, intermediate, inactive, and multiwindow states where supported.

Source: [Apple HIG — Windows](https://developer.apple.com/design/human-interface-guidelines/windows). Checked 2026-09-08.
