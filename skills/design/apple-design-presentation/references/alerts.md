# Alerts

- Reserve alerts for critical information requiring immediate attention or an important decision.
- Avoid routine informational alerts, launch-time interruptions, and confirmations for ordinary actions that can be undone.
- Use a clear title and add explanatory text only when it contributes information.
- Label buttons with the actual action. Provide a safe cancellation path for destructive choices and use roles accurately.

For choices following an intentional action, consider an action sheet instead. Verify dismissal, default action, and focus on the target platform; visual emphasis should not make a harmful choice the accidental default.

Source: [Apple HIG — Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts). Checked 2026-09-08.
