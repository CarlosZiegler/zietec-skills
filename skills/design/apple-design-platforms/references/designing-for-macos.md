# Designing for macOS

- Favor efficient work with multiple windows and apps. Use available space to reduce unnecessary navigation depth while keeping content readable.
- Support window movement, resizing, hiding, restoration, and full-screen use through familiar system behavior.
- Expose commands in the menu bar, with standard keyboard shortcuts and keyboard-only operation where possible.
- Provide precise pointing interactions for selection and editing, including sensible behavior when windows become inactive.
- Let people adapt relevant toolbars, views, and presentation to their work style.

Review a Mac design as a desktop workflow: opening content, switching windows, using commands, editing, and returning later. Ported touch layouts often need changes to command placement, density, and navigation even when the underlying task is identical.

Source: [Apple HIG — Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos). Checked 2026-09-08.
