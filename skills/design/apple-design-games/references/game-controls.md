# Game controls

- Support default platform input and detect connected controllers, updating prompts to match the actual device.
- Map movement, camera, selection, and Back behavior predictably.
- Keep touch controls reachable, appropriately sized, and responsive with visible press states.
- Let players customize relevant key bindings and use comfortable key placement.
- Support controller changes and multiple controllers where the game needs them.

Test during gameplay, including connection changes and accessibility alternatives. Controller symbols should correspond to the connected device instead of generic labels that require translation.

Source: [Apple HIG — Game controls](https://developer.apple.com/design/human-interface-guidelines/game-controls). Checked 2026-09-08.
