# Designing for games

- Reach playable value quickly with strong defaults and learning through play.
- Adapt text, controls, menus, and artwork to each display and input model.
- Support the platform’s normal inputs as well as appropriate optional controllers.
- Provide accessible cues, personalization, and inclusive representation.
- Use system gaming, saved progress, audio, or haptics where they enrich the experience.

Review actual gameplay as well as menus. Defer nonessential accounts, downloads, ratings, and purchases rather than placing every integration before the first playable moment.

Source: [Apple HIG — Designing for games](https://developer.apple.com/design/human-interface-guidelines/designing-for-games). Checked 2026-09-08.
