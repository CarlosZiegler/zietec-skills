# Page controls

- Use page indicators for an ordered, flat set of pages, with an unmistakable current page.
- Keep page counts manageable even when the component technically supports many items.
- Use simple indicator customization only when it adds meaning; avoid a collection of unrelated symbols or decorative colors.
- On touch platforms, account for scrubbing behavior rather than animating every intermediate page transition.
- On Apple Watch, consider purposeful vertical pages with content that fits the task at a glance.

Do not use dots as a substitute for a labeled hierarchy. Verify navigation, touch targets, and accessibility when the indicator is interactive rather than merely descriptive.

Source: [Apple HIG — Page controls](https://developer.apple.com/design/human-interface-guidelines/page-controls). Checked 2026-09-08.
