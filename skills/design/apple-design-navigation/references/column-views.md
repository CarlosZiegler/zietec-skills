# Column views

- Use columns to browse a hierarchy one level at a time, beginning with the root in the first column.
- Selecting a parent should expose its children in the next column while retaining the surrounding path.
- Let people resize columns and consider showing useful detail when the selected item has no children.
- For iPadOS or visionOS hierarchy, evaluate a split view instead.

Choose this pattern for deliberate hierarchical browsing, not for unrelated side-by-side cards. Verify long names, deep levels, selection, and keyboard navigation with representative data.

Source: [Apple HIG — Column views](https://developer.apple.com/design/human-interface-guidelines/column-views). Checked 2026-09-08.
