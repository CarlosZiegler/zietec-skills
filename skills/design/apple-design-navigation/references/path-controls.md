# Path controls

- Use a path control to represent a selected file or folder’s file-system location.
- Choose the appropriate standard path style for the available space and interaction.
- Place it within the window’s content area, following the platform guidance rather than treating it as custom window chrome.

Make the displayed path correspond to the selected item or current folder. Do not use a file-system path control as a generic replacement for app navigation when the information is not actually a file hierarchy.

Source: [Apple HIG — Path controls](https://developer.apple.com/design/human-interface-guidelines/path-controls). Checked 2026-09-08.
