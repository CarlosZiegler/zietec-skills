# Search fields

- Make the searchable scope understandable through placement and concise placeholder text.
- Offer useful suggestions, completions, and filtering; begin results as typing progresses when feasible.
- Start with a broad scope and make narrower scopes or tokens understandable.
- On iOS, choose among a discovery-oriented search tab, a quick search button, toolbar search, or an inline field according to the task.
- On iPad and Mac, distinguish global toolbar search from filtering inside a sidebar, and adapt placement as windows resize.

Consult the current page’s platform sections before prescribing top or bottom placement. Search location should express its relationship to the content, not follow an outdated universal rule.

Source: [Apple HIG — Search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields). Checked 2026-09-08.
