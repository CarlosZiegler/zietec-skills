# Searching

- Give search a prominent place when it is a primary task, and avoid requiring people to guess among disconnected search entry points.
- Keep the current scope visible and provide relevant suggestions or refinements.
- Consider privacy before showing previous queries or personalized suggestions.
- Support finding within a document separately from searching the whole app when both are useful.
- Consider Spotlight, file metadata, system open/save interfaces, and Quick Look for discoverable document content.

Specify what a result opens and how the person returns to the query. Review no-results and restricted-content behavior along with the successful path so search remains useful beyond an ideal query.

Source: [Apple HIG — Searching](https://developer.apple.com/design/human-interface-guidelines/searching). Checked 2026-09-08.
