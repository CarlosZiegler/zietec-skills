# Tab views

- Use a tab view for closely related panes occupying the same area, especially in desktop interfaces.
- Keep each pane’s controls scoped to its own content and label tabs by their contents.
- Avoid replacing the tab selector with a pop-up button, and keep the number of tabs manageable; the source advises no more than six.
- Preserve sensible margins around an inset tab view where the platform expects them.

Distinguish this component from top-level app tab bars and from platform-specific paging presentations. Read the platform section before mapping a framework’s similarly named view to a visual design.

Source: [Apple HIG — Tab views](https://developer.apple.com/design/human-interface-guidelines/tab-views). Checked 2026-09-08.
