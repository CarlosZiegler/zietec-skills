# Outline views

- Use an outline for hierarchical rows, with hierarchy in the first column; use a plain table for nonhierarchical data.
- Provide descriptive column headings, useful sorting, and resizable columns where appropriate.
- Preserve expanded and collapsed state so returning to the view does not erase the person’s work.
- Make nested expansion efficient and offer search for large hierarchies.
- Keep cell text readable; consider middle truncation for identifiers where both ends matter.

Review selected, expanded, edited, and filtered states together. Additional attribute columns should supplement the hierarchy without creating competing indentation systems.

Source: [Apple HIG — Outline views](https://developer.apple.com/design/human-interface-guidelines/outline-views). Checked 2026-09-08.
