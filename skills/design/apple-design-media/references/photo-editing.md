# Photo editing

- Fit the extension into the system Photos editing experience, preserving its existing top toolbar.
- Let people preview changes before completion.
- Confirm cancellation when edits would otherwise be lost.
- Use the app’s icon for the extension and preserve the original media through the platform’s editing model.

Review commit and cancel as distinct paths. Do not add competing navigation chrome or make an edit permanent merely because the preview was displayed.

Source: [Apple HIG — Photo editing](https://developer.apple.com/design/human-interface-guidelines/photo-editing). Checked 2026-09-08.
