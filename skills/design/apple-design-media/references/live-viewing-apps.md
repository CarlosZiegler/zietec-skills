# Live-viewing apps

- Make live content prominent and visibly distinguish it from on-demand content.
- Reduce the steps needed to begin watching and give immediate feedback when changing channels.
- Keep audio consistent with the current viewing context.
- Let people browse a program guide while retaining access to current playback.
- Expose recording controls and future-program scheduling in the relevant content views.

Review live, delayed, recorded, and unavailable program states. A clear program guide needs current timing, understandable categories, and a fast return to watching.

Source: [Apple HIG — Live-viewing apps](https://developer.apple.com/design/human-interface-guidelines/live-viewing-apps). Checked 2026-09-08.
