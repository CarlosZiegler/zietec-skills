# SharePlay

- Make a shared activity easy to discover, describe, and join with minimal preparatory work.
- Preserve synchronized shared state while keeping private information and personal presentation choices separate.
- Handle participants joining, leaving, and returning smoothly.
- Explain access requirements and reduce unnecessary delays for nonsubscribers where possible.
- In visionOS, choose an appropriate spatial arrangement for the activity.

Test a real multi-person session when available. Decide which changes affect everyone and which stay personal; synchronization alone does not make that distinction understandable.

Source: [Apple HIG — SharePlay](https://developer.apple.com/design/human-interface-guidelines/shareplay). Checked 2026-09-08.
