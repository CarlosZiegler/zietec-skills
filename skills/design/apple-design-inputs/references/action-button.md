# Action button

- Expose essential functions that benefit from quick access through the Action button.
- Use short descriptive action names and prefer system instruction for discovering the feature.
- On iPhone, let appropriate actions complete without unnecessarily leaving the current context.
- On Apple Watch Ultra, use subsequent presses for useful progression through an activity and respect the documented pause combination.

Check device and platform support and the person’s configured action. Do not assume the app owns the button globally or can redefine system-level behavior.

Source: [Apple HIG — Action button](https://developer.apple.com/design/human-interface-guidelines/action-button). Checked 2026-09-08.
