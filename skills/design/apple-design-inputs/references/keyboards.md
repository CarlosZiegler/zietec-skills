# Keyboards

- Support standard editing, navigation, and command shortcuts, plus Full Keyboard Access where possible.
- Create custom shortcuts for frequent app-specific work, preserving established modifier conventions.
- Avoid borrowing a standard shortcut or extending an unrelated one with an extra modifier.
- Let the system handle localization and mirroring where supported.
- Make commands and shortcut titles understandable without a pointer.

Trace the task with a physical keyboard: entering, leaving, selecting, activating, and cancelling. Hardware keyboard behavior is distinct from choosing a suitable onscreen keyboard.

Source: [Apple HIG — Keyboards](https://developer.apple.com/design/human-interface-guidelines/keyboards). Checked 2026-09-08.
