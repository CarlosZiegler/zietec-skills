# Widgets

- Choose a focused, recurring need with timely information and simple useful interactions.
- Design each supported size and context deliberately; extra space should add value, not arbitrary density.
- Keep data current within system constraints and use native date or time rendering where appropriate.
- Make app-opening interactions lead to the exact relevant destination.
- Preserve clarity across full-color, accented or tinted, and other applicable rendering contexts.

Verify current families, margins, interactive capabilities, and privacy behavior. A widget is not a miniature copy of the app, and its visual update design must respect actual system refresh behavior.

Source: [Apple HIG — Widgets](https://developer.apple.com/design/human-interface-guidelines/widgets). Checked 2026-09-08.
