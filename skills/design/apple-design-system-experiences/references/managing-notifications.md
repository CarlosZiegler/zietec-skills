# Managing notifications

- Request permission in a context that explains the value of notifications.
- Respect Focus, delivery preferences, and the person’s ability to adjust notification behavior.
- Classify urgency honestly; reserve Time Sensitive for information that truly matters at that moment.
- Obtain the appropriate opt-in for promotional notifications and never classify marketing as Time Sensitive.
- Make notification settings understandable within the app.

Separate permission, subscription categories, and message content. Repeated pressure after denial is not a substitute for a useful alternative inside the app.

Source: [Apple HIG — Managing notifications](https://developer.apple.com/design/human-interface-guidelines/managing-notifications). Checked 2026-09-08.
