# Live Activities

- Use a Live Activity for an event or task with a meaningful beginning and end.
- Focus on essential evolving information and appropriate quick interactions, avoiding advertisements and sensitive content.
- Design each applicable compact, minimal, expanded, Lock Screen, and cross-device presentation.
- Keep layouts readable and stable as values change, adapting to supported dimensions.
- Make the end state and opening destination appropriate to the activity.

Consult current platform availability, update limits, and interaction guidance. Do not imply the app owns Dynamic Island or add in-app decorations that point toward it.

Source: [Apple HIG — Live Activities](https://developer.apple.com/design/human-interface-guidelines/live-activities). Checked 2026-09-08.
