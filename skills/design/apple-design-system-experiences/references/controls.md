# Controls

- Use system controls for valuable actions or toggles available from Control Center, the Lock Screen, or Action button.
- Choose descriptive symbols and accurate state labels, updating them after changes or completion.
- Provide required parameters and placeholders so the system can present the action coherently.
- Protect sensitive locked-device information and require authentication for security-affecting actions.

Keep simple actions useful without an unnecessary app launch. Check current capability and rendering requirements, and distinguish an action button from a toggle whose displayed state must remain synchronized.

Source: [Apple HIG — Controls](https://developer.apple.com/design/human-interface-guidelines/controls). Checked 2026-09-08.
