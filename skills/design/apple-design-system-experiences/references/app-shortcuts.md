# App Shortcuts

- Expose common, valuable actions with clear parameters and familiar vocabulary.
- Consider current app schemas for functionality the system already models.
- Keep voice interactions short and provide enough result context for audio-only use.
- Make shortcuts discoverable and use brief natural activation phrases.
- Avoid forcing a long conversation for a task that should be quick.

Specify missing-information behavior and what happens after completion. Verify current App Intents and platform availability instead of assuming every app action can run in every system context.

Source: [Apple HIG — App Shortcuts](https://developer.apple.com/design/human-interface-guidelines/app-shortcuts). Checked 2026-09-08.
