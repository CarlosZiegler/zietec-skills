# Snippets

- Use a snippet to show an action’s result or obtain a relevant confirmation in a compact system surface.
- Keep text concise and legible, with visual content that makes the task apparent.
- Give confirmation buttons labels that describe the actual action.
- Coordinate custom content with the surrounding system dialogue and controls.

Design both spoken and visual context where relevant. The snippet should resolve a focused moment, not recreate a full app screen or require unexplained navigation inside a compact response.

Source: [Apple HIG — Snippets](https://developer.apple.com/design/human-interface-guidelines/snippets). Checked 2026-09-08.
