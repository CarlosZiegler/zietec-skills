# Siri

- Integrate popular actions and relevant content using terminology people recognize in the app.
- Prefer built-in responses when they already communicate the result.
- Write concise responses that work audibly and visually, using device-independent language where possible.
- Explain failure and ask manageable follow-up questions rather than reading an excessive option list.
- Keep advertising out of assistant interactions.

Consult the current source and SDK for Siri capabilities and contextual integration. Do not infer universal availability from an announced feature or assume the same behavior across all devices and OS versions.

Source: [Apple HIG — Siri](https://developer.apple.com/design/human-interface-guidelines/siri). Checked 2026-09-08.
