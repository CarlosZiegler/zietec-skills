# ID Verifier

- Request only the identity attributes required for the in-person task, such as an age threshold rather than unnecessary personal details.
- Distinguish Display Only and Data Transfer experiences and their implications.
- Provide a clear control to begin verification and appropriate organization context.
- For a visual verification flow, let the operator record the relevant confirmation.

Verify current eligibility, registration, hardware, and API requirements before implementation. Designing a verification interface does not establish that an organization is authorized to collect or retain identity data.

Source: [Apple HIG — ID Verifier](https://developer.apple.com/design/human-interface-guidelines/id-verifier). Checked 2026-09-08.
