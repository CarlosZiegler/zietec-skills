# CareKit

- Match task presentation to the care activity: a simple action, instructions, event log, checklist, or structured set of steps.
- Keep descriptions accurate and simple, adding useful visual instruction for complex tasks.
- Present trends and progress with clear units, labels, and appropriate aggregation.
- Request health access contextually and preserve system sharing controls.
- Use notifications sparingly and keep branding subordinate to the care task.

Check the current framework and care-plan model instead of assuming older component versions are still the implementation target. Clinical instructions and measurement interpretation require domain review beyond the HIG.

Source: [Apple HIG — CareKit](https://developer.apple.com/design/human-interface-guidelines/carekit). Checked 2026-09-08.
