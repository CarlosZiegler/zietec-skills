# Color wells

- Use a color well to show and adjust the color of a selected object or attribute.
- Prefer the system color picker for a familiar set of selection methods and controls.
- Keep the connection between the well and the affected content evident.

Evaluate a custom picker only for a concrete need that the system interface cannot meet. Inspect the platform section before specifying persistent picker behavior or multiple wells, and provide accessible naming that identifies the property being changed.

Source: [Apple HIG — Color wells](https://developer.apple.com/design/human-interface-guidelines/color-wells). Checked 2026-09-08.
