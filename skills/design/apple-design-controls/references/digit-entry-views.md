# Digit entry views

- Use the full-screen digit-entry presentation for a focused numeric sequence such as a PIN on a supported platform.
- State why the digits are requested with an appropriate title or prompt.
- Use secure digit fields for private codes.

Check platform availability and the native interaction before choosing this specialized control. A general numeric form field does not necessarily need to interrupt the entire screen with a digit-entry view.

Source: [Apple HIG — Digit entry views](https://developer.apple.com/design/human-interface-guidelines/digit-entry-views). Checked 2026-09-08.
