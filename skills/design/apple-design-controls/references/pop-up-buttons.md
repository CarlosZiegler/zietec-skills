# Pop-up buttons

- Use a pop-up button for one selection from a flat set of mutually exclusive choices.
- Show a useful default and make the purpose predictable before the menu opens.
- Keep the selected value understandable after the menu closes.
- Consider this compact presentation when displaying every option simultaneously adds little value.
- Add a custom option only when it offers a meaningful extension to the available choices.

Distinguish selection from action: a pop-up generally represents the current option, while a pull-down menu commonly performs a command. Use the actual platform behavior in the implementation.

Source: [Apple HIG — Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons). Checked 2026-09-08.
