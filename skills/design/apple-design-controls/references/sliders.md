# Sliders

- Use a slider for values within a range where dragging is a useful way to adjust them.
- Make minimum and maximum meaning clear and use familiar directionality, including appropriate RTL behavior.
- Add a field or stepper when people also need exact values or large changes.
- Provide live feedback when it helps people understand the effect; consider ticks and labels where precision matters.
- For iOS and iPadOS audio volume, use the system volume interface rather than a custom generic slider.

Verify keyboard and accessibility adjustment, bounds, and value formatting. A visually smooth control still needs a usable precise alternative when the task demands accuracy.

Source: [Apple HIG — Sliders](https://developer.apple.com/design/human-interface-guidelines/sliders). Checked 2026-09-08.
