# Segmented controls

- Use segments for a small set of closely related choices affecting the same object, state, or view.
- Keep segment presentation and sizing consistent; prefer either text or icons throughout the group.
- Use concise noun labels that identify the available choices.
- Distinguish selection rules: some Mac segmented controls permit multiple selections, while many other uses represent one choice.
- For Mac main-window view switching, consider the platform’s tab-view pattern; for TV filtering, consider a split view.

Avoid turning a segmented control into a crowded row of unrelated commands or top-level destinations. Review localization and focus spacing before committing to the layout.

Source: [Apple HIG — Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls). Checked 2026-09-08.
