# Steppers

- Use a stepper to increase or decrease a value by meaningful increments.
- Display the current value nearby and make its relationship to the control obvious.
- Pair it with editable numeric entry when traversing a large range would require excessive interaction.
- On Mac, consider supported accelerated adjustment for large ranges.

Specify bounds, units, increment size, and behavior at the limits. Avoid using a stepper merely because the value is numeric; the expected frequency and size of changes determine whether it is suitable.

Source: [Apple HIG — Steppers](https://developer.apple.com/design/human-interface-guidelines/steppers). Checked 2026-09-08.
