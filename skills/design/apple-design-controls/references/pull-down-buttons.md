# Pull-down buttons

- Use a pull-down button for commands or items directly associated with the button’s purpose.
- Keep the menu focused; a single pull-down should not absorb every action in the view.
- Use concise labels and meaningful icons only where they help recognition.
- Make destructive consequences visible and provide appropriate confirmation when required.
- A More menu can hold secondary actions on iOS and iPadOS.

Unlike a pop-up selection, choosing an item typically performs an action. Make the initiating button’s meaning clear enough that people can predict the category of commands before opening the menu.

Source: [Apple HIG — Pull-down buttons](https://developer.apple.com/design/human-interface-guidelines/pull-down-buttons). Checked 2026-09-08.
