# Virtual keyboards

- Select a system keyboard that matches the expected data, and use a return-key label that describes the next step.
- Use the keyboard layout guide and appropriate accessory placement so fields remain visible and reachable.
- Replace the keyboard with a custom input view only when it serves the task better than standard entry.
- For a custom keyboard extension, preserve an obvious way to switch keyboards and avoid duplicating system features.
- Use standard keyboard sound behavior where applicable.

Account for floating, resized, or dismissed keyboards on supported platforms. Virtual keyboards are not a substitute for testing physical-keyboard shortcuts and focus separately.

Source: [Apple HIG — Virtual keyboards](https://developer.apple.com/design/human-interface-guidelines/virtual-keyboards). Checked 2026-09-08.
