# Token fields

- Use tokens when individual text entries represent discrete, manipulable entities such as recipients.
- Offer relevant suggestions while typing, then make conversion into tokens predictable.
- Consider alternate ways to commit text as a token and choose a suggestion delay that fits the task.
- Add contextual actions when they provide useful detail or manipulation of a token.

Keep the entity’s identity and selection state understandable. Review editing, deleting, reordering, and moving entries with both keyboard and pointer; tokenization should reduce complexity instead of hiding what the underlying text means.

Source: [Apple HIG — Token fields](https://developer.apple.com/design/human-interface-guidelines/token-fields). Checked 2026-09-08.
