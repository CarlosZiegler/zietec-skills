# Pickers

- Use a picker for a meaningful set of distinct values, especially when typing would introduce avoidable errors.
- Keep options predictably ordered and compatible with localization.
- Choose date-picker style according to available space and the way people need to specify the date or time.
- Avoid an unnecessary navigation transition just to expose the picker.
- Reduce minute granularity when the task does not need precision.

Check how the selected framework adapts the control on the target platform. A wheel, calendar, compact field, or other native style should support the actual choice rather than imitate a screenshot from another device.

Source: [Apple HIG — Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers). Checked 2026-09-08.
