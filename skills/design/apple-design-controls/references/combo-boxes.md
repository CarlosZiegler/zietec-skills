# Combo boxes

- Use a combo box when people need both suggested values and the ability to enter a custom value.
- Populate it with a meaningful default and a label that explains the kind of value expected.
- Keep suggestions relevant and short enough for the field’s width.
- Do not imply that entering a custom value automatically adds it to the predefined list.

Choose a stricter selection control when arbitrary input is invalid. Verify validation and keyboard behavior so the distinction between a suggestion and a required option stays clear.

Source: [Apple HIG — Combo boxes](https://developer.apple.com/design/human-interface-guidelines/combo-boxes). Checked 2026-09-08.
