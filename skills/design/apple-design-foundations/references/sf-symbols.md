# SF Symbols

- Choose a symbol that matches the action’s established meaning and verify its availability on the minimum supported OS.
- Match weight and scale to surrounding typography. Select monochrome, hierarchical, palette, or multicolor rendering based on clarity in the real context.
- Use variable color for changing values or activity; use hierarchy to express layers or depth.
- Animate symbols only when the effect communicates a relevant event or state. Check reduced-motion behavior and repeated use.
- For custom symbols, test all required weights, variants, layer annotations, rendering modes, and animations; supply accessibility descriptions.

Consult the current SF Symbols catalog and usage restrictions. Do not invent symbol names or assume a symbol introduced in the current release exists on older targets.

Source: [Apple HIG — SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols). Checked 2026-09-08.
