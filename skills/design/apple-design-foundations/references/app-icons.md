# App icons

- Build a distinctive, simple identity that remains recognizable across platforms and appearances.
- For current layered workflows, create clear foreground shapes, a supporting background, and appropriately unmasked layers. Prefer vector source artwork where supported.
- Keep essential content centered so masking and platform effects do not crop it. Let the system provide its intended visual effects.
- Preserve recognizable features between light, dark, and tinted variants; review each variant next to system icons.
- Use text only when essential, and avoid recreating interface elements or Apple hardware.

Read the current platform specifications before exporting. Layer counts, shapes, safe zones, sizes, and rendering differ by platform; inspect Icon Composer previews and small system placements rather than delivering one generic rounded-square image.

Source: [Apple HIG — App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons). Checked 2026-09-08.
