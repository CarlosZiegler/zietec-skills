# Branding

- Express identity through the app icon, language, considered accents, and typography that remains usable.
- Keep content and the person’s task dominant. Repeating the logo throughout the interface rarely adds useful context.
- Preserve standard interaction patterns so distinctive styling does not create unnecessary learning work.
- Treat a launch screen as a transition into usable content, not as an advertisement.
- Check Apple’s current trademark and asset requirements when using platform marks.

Judge each branded element by the role it serves. A custom font, color, or animation should preserve hierarchy, accessibility, and recognizable control behavior. Apply the brand consistently without requiring every screen or system surface to carry a prominent logo.

Source: [Apple HIG — Branding](https://developer.apple.com/design/human-interface-guidelines/branding). Checked 2026-09-08.
