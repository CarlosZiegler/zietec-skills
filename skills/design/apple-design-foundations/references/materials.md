# Materials

- Reserve Liquid Glass for the navigation and control layer. Use standard materials when separating elements within content.
- Apply effects selectively; repeating glass treatments throughout the content weakens hierarchy and can obscure what matters.
- Choose material variants by context and meaning. The clear Liquid Glass variant is intended for placement over visually rich backgrounds.
- Check text and symbol legibility against changing content, not just a fixed sample image.
- In visionOS windows, preserve the translucent system treatment unless a specific task requires another approach.

Prefer native material behavior and check the target OS before choosing APIs. A static blur or opacity value is not an equivalent specification for all of the material’s adaptive behavior.

Source: [Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials). Checked 2026-09-08.
