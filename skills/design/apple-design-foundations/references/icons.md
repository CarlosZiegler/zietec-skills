# Icons

- Give each interface icon a recognizable concept and a simple silhouette. Use familiar symbols for familiar actions.
- Keep stroke weight, visual scale, and treatment consistent with neighboring text and controls; adjust optical alignment when needed.
- Provide an accessible label for meaningful custom icons. Avoid text embedded in a glyph unless the concept requires it and localization is addressed.
- Prefer vector assets for custom interface icons, and test at the smallest actual presentation size.
- Distinguish interface glyphs from expressive app icons. Do not imitate Apple hardware as custom artwork.

For document icons, consult platform-specific guidance on simplified small variants and placement around the folded corner. An icon’s source canvas size does not establish its perceived weight in the interface.

Source: [Apple HIG — Icons](https://developer.apple.com/design/human-interface-guidelines/icons). Checked 2026-09-08.
