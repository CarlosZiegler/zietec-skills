# Wallet

- Offer to add useful passes when issued and provide access to existing passes without duplicate additions.
- Keep pass fronts focused, recognizable, legible, and appropriate for the supported devices.
- Update relevant information, set expiration, and use change messages for genuinely time-critical updates.
- Obtain permission before deleting passes and add related passes together when useful.
- For identity-related flows, request only needed information at the necessary moment and explain retention.

Check current pass types, field limits, barcode behavior, artwork specifications, and button requirements. A pass preview is not a validated distributable pass.

Source: [Apple HIG — Wallet](https://developer.apple.com/design/human-interface-guidelines/wallet). Checked 2026-09-08.
