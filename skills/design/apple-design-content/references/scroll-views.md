# Scroll views

- Preserve standard scrolling gestures and shortcuts, and make additional content discoverable.
- Avoid nesting scroll containers with the same orientation.
- Use paging, automatic positioning, or zoom limits only where they support the content.
- Apply scroll-edge effects when content moves behind floating interface elements, generally using the automatic style and one effect per view.
- On visionOS, evaluate Look to Scroll for primary reading or browsing content with clear scroll regions.

Review sticky controls, keyboard avoidance, restored position, and accessibility. A custom scroll animation should not interfere with system interaction or obscure the person’s place.

Source: [Apple HIG — Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views). Checked 2026-09-08.
