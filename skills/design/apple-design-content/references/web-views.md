# Web views

- Use a web view to embed appropriate rich web content inside the app.
- Provide forward and back navigation when people can follow links and need to retrace their steps.
- Consult the source’s guidance before using embedded web views as the foundation of a browser experience.

Make the transition between native and web content understandable. Review navigation, loading, and error states rather than presenting the successful HTML view as the whole experience.

Source: [Apple HIG — Web views](https://developer.apple.com/design/human-interface-guidelines/web-views). Checked 2026-09-08.
