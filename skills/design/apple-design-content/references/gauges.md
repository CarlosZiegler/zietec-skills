# Gauges

- Use a gauge to show a current numeric value in a meaningful range.
- Label the current value and endpoints succinctly where needed to explain that range.
- Use color or a gradient as additional context, keeping the meaning available without color alone.
- Choose a continuous or other supported style based on the range and platform.

Distinguish a measured value from operation progress. A gauge needs understandable units and range semantics; it should not resemble a loading indicator when no task is underway.

Source: [Apple HIG — Gauges](https://developer.apple.com/design/human-interface-guidelines/gauges). Checked 2026-09-08.
