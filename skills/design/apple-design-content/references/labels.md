# Labels

- Use labels for short, noneditable text that identifies controls, content, or context.
- Prefer system typography and semantic label colors to communicate hierarchy and adapt to appearance.
- Let people select and copy useful text when that supports their task.

Check long translations and larger text in the actual container. Static text is not necessarily decorative: ensure meaningful labels remain available to assistive technology without redundant repetition around related controls.

Source: [Apple HIG — Labels](https://developer.apple.com/design/human-interface-guidelines/labels). Checked 2026-09-08.
