# Image views

- Use an image view when displaying the image is the view’s primary job.
- Choose appropriate scaling and cropping and preserve legibility when placing text over an image.
- Keep animated frames consistently sized.
- Use a real button for a clickable image and an image well when the image itself is editable on Mac.

For interface actions, prefer a symbol or glyph with appropriate semantics. A decorative image view should not silently acquire interaction without the focus, labels, and feedback that interaction requires.

Source: [Apple HIG — Image views](https://developer.apple.com/design/human-interface-guidelines/image-views). Checked 2026-09-08.
