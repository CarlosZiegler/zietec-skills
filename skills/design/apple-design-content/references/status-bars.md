# Status bars

- Preserve access to system status information in ordinary use.
- Prevent content beneath the status region from making that information difficult to see.
- Hide the status bar temporarily only when it improves a full-screen experience, such as media.

Test layout and legibility as appearance and orientation change. Permanent removal should not be a default styling choice, because time, connectivity, and battery information remain useful context.

Source: [Apple HIG — Status bars](https://developer.apple.com/design/human-interface-guidelines/status-bars). Checked 2026-09-08.
