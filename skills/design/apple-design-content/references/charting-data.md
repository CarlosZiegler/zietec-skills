# Charting data

- Begin with the insight or decision the chart should support.
- Prefer familiar chart types; teach an unfamiliar representation when the task truly benefits from it.
- Keep the initial view focused, allowing people to request additional detail.
- Match size and information density to the chart’s function and available space.
- Maintain continuity of scales, colors, and meaning across related charts, changing them only for a clear reason.

Add descriptive context and accessible access to the important information. A chart is useful when it reveals relationships, not simply because it makes a screen more visually varied.

Source: [Apple HIG — Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data). Checked 2026-09-08.
