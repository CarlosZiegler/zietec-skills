# Image wells

- Use an image well when people need to replace or edit the displayed image through standard interactions.
- Support appropriate paste, copy, deletion, and drag-and-drop behavior.
- Make the standard editing commands available when the corresponding operations are supported.
- Restore a sensible default if deleting the image cannot leave the interface empty.

Keep the difference between viewing and replacing the image apparent. Review selection and keyboard behavior so the editable surface does not act like an unexplained drop target.

Source: [Apple HIG — Image wells](https://developer.apple.com/design/human-interface-guidelines/image-wells). Checked 2026-09-08.
