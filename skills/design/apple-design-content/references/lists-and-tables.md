# Lists and tables

- Prefer lists or tables for text-led content and attributes people need to scan or compare.
- Use meaningful row styles, concise content, and clear selection feedback.
- Preserve readability of long values and provide descriptive column headings.
- Offer editing, ordering, sorting, or column resizing when these support the task.
- For Mac hierarchical data, consider an outline rather than a plain table.

Check platform-specific row accessories and focus behavior. An information button should reveal information about the row; it should not silently perform an unrelated action.

Source: [Apple HIG — Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables). Checked 2026-09-08.
