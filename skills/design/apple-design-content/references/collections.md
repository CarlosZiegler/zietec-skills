# Collections

- Use collections for visually led, ordered content, especially images.
- Prefer familiar grid or row arrangements unless a custom layout adds real value.
- Make items easy to identify and select, with clear feedback for insertion, deletion, or reordering.
- Consider a table for primarily textual data.

Treat dynamic layout changes carefully so content does not unexpectedly move away from the person’s target. Verify the collection with mixed content, missing artwork, long labels, and the intended input methods.

Source: [Apple HIG — Collections](https://developer.apple.com/design/human-interface-guidelines/collections). Checked 2026-09-08.
