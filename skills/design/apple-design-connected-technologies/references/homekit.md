# HomeKit

- Reflect the established hierarchy of homes, rooms, accessories, services, scenes, and automations.
- Support multiple homes and avoid duplicating conflicting settings.
- Prefer system setup, explain Home-data access, and preserve people’s existing configuration.
- Suggest useful names that work with voice interaction and teach relevant commands where helpful.
- Add custom shortcuts for accessory-specific needs the standard model does not cover.

Review remote state and setup failures without issuing real accessory commands during a design exercise. Verify current integration and naming requirements before implementing.

Source: [Apple HIG — HomeKit](https://developer.apple.com/design/human-interface-guidelines/homekit). Checked 2026-09-08.
