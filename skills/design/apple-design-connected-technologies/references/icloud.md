# iCloud

- Keep content and useful app state available across devices without requiring manual synchronization.
- Preserve a useful experience when iCloud is unavailable.
- Respect storage and make conflicts prompt and understandable to resolve.
- Explain the consequences of deletion across synchronized devices.
- Include relevant cloud content in search and preserve game progress when appropriate.

Distinguish local success from completed synchronization. Review offline edits, reconnection, conflicts, and deletion rather than implying that every visible change has already reached every device.

Source: [Apple HIG — iCloud](https://developer.apple.com/design/human-interface-guidelines/icloud). Checked 2026-09-08.
