# Ornaments

- Use an ornament for persistent controls related to a visionOS window without crowding its content.
- Prefer system toolbars and tab bars when they already support the need.
- Keep the ornament’s position connected to the window and balance multiple ornaments carefully.
- Avoid making its width exceed the associated window without good reason.
- Consider borderless buttons and a stable visible presentation.

Review placement and targeting at actual scale. An ornament should support the window’s task, not become an independent floating navigation system with unclear ownership.

Source: [Apple HIG — Ornaments](https://developer.apple.com/design/human-interface-guidelines/ornaments). Checked 2026-09-08.
