# Printing

- Expose printing where the content supports it, using the system interface.
- Present relevant options and clarify dependencies between them.
- Keep advanced controls separate from frequent choices and preview effects when useful.
- Store document-specific settings with the document where appropriate.

Choose custom print controls only for options the system does not provide. Review page content and document state, not just the placement of a Print button.

Source: [Apple HIG — Printing](https://developer.apple.com/design/human-interface-guidelines/printing). Checked 2026-09-08.
