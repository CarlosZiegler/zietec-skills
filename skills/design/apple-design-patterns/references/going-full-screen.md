# Going full screen

- Offer full-screen use when it supports focused content or work, using system behavior where available.
- Preserve essential commands and provide a familiar way to reveal hidden controls.
- Let people decide when to enter or leave and resume their prior context after switching away.
- Adapt layout without unnecessarily changing display modes or forcing window sizes.

Distinguish full-screen windows from visionOS immersion and from platforms where apps already occupy the display. Do not hide all navigation permanently in pursuit of a cleaner screenshot.

Source: [Apple HIG — Going full screen](https://developer.apple.com/design/human-interface-guidelines/going-full-screen). Checked 2026-09-08.
