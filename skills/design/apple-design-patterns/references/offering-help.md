# Offering help

- Derive help from the task or unfamiliar feature, avoiding explanations of standard interactions people already know.
- Prefer brief, actionable contextual tips with appropriate display conditions.
- Use consistent language and inclusive illustrations.
- For tooltips, describe the indicated control’s result without simply repeating its name.

Offer a path to deeper help only when necessary. Repeated tips should not cover important controls or interrupt an established workflow; evaluate who needs each tip and when it stops being useful.

Source: [Apple HIG — Offering help](https://developer.apple.com/design/human-interface-guidelines/offering-help). Checked 2026-09-08.
