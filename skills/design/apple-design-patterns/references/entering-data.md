# Entering data

- Request only the information the task needs and use permitted system data to avoid asking for it again.
- Prefer appropriate choices, paste, or drag and drop over unnecessary typing.
- Clearly identify required fields and expected formats.
- Protect private entry and avoid prepopulating a password yourself.
- Validate at useful moments with actionable feedback.

Keep data entry proportional to the device and context. Distinguish helping people use system credential features from inserting credentials into a custom form, and preserve the person’s work when a field needs correction.

Source: [Apple HIG — Entering data](https://developer.apple.com/design/human-interface-guidelines/entering-data). Checked 2026-09-08.
